\# Cinema-with-Coffee



AI-based storytelling system that generates structured creative content like characters, scenes, and screenplays using modular Python components and AI integration (Ollama-based).



\## Features

\- Character generation

\- Scene \& screenplay creation

\- Tone analysis

\- Consistency checking

\- Template-based storytelling workflow



\## Run

1\. Install dependencies

2\. Setup Ollama model

3\. Run main Python file
